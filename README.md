# Mood Paper
Procedural static and animated stylized wallpapers: flat layered shapes, mood-driven palettes, optional pixel art and dithering.

Open `index.html` from disk (no server): one page with the scene builder (palette + preset + seed, seamless loop, PNG / GIF export) and the gallery (every preset x every reference palette, click one to open it in the builder). Notes: [docs/RESEARCH.md](docs/RESEARCH.md), [docs/REFERENCES.md](docs/REFERENCES.md), API in [USAGE.md](USAGE.md).
